📋 HIZLI BAŞLANGIÇ (5 DAKİKA)

1. Terminali açın ve proje klasörüne gidin:
   
   cd snn_reflex_proto

2. Bağımlılıkları yükleyin:
   
   pip install -r requirements.txt

3. Kurulumu test edin:
   
   python test_setup.py

4. Modeli eğitin (5-10 dakika):
   
   python train.py

5. Canlı demo çalıştırın:
   
   python run.py
